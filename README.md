# Digit Recognition with CNN and KNN

This project applies Convolutional Neural Networks (CNN) and K-Nearest Neighbors (KNN) to classify handwritten digits using the MNIST dataset. Built as part of the Kaggle Digit Recognizer competition, the notebook includes data preprocessing, model training, accuracy evaluation, and Kaggle submission.

## Tools & Libraries
- Python
- TensorFlow / Keras
- scikit-learn
- NumPy
- pandas
- matplotlib

## Features
- Image classification using CNN
- Baseline comparison with KNN
- Accuracy and RMSE evaluation
- Kaggle-ready prediction output
